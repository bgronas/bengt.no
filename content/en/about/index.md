This is the personal engineering site of Bengt Grønås.

The articles cover technology, sustainability, cloud native platforms, orchestration, datacentre management and home automation, with the occasional personal note. Articles are published in Norwegian Bokmål and in British English; where both versions exist, the language menu links them.

## Elsewhere

- [GitHub](https://github.com/bgronas)
- [LinkedIn](https://linkedin.com/in/bgronas)

## How the site is built

The site is static. Articles are Markdown files in a Git repository, rendered with Hugo and the Blowfish theme and served by GitHub Pages. It uses no analytics, no cookies and no third-party comment system.
